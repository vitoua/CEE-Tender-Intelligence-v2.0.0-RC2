# Національні конектори RC2: що саме змінено

Це власні модулі, а не перейменовані виклики TED. TED залишається окремим джерелом. Усі інші файли функціоналу RC1 включені в повний пакет.

## Словаччина
Список: офіційний ÚVO, а не порожній discovery на EVO. Зі списку беруться реальні detail URL із cHash, ID, назва й замовник. Картка ÚVO читається за назвами полів. Якщо немає дедлайну/публікації, конектор переходить за фактичним посиланням на публічну EVO-картку. Дата оновлення списку не підміняє дату публікації. Вартість не вигадується.

## Литва
Новий CVP IS: prepareCurrentOpportunities.do?currentType=cft. Звідси беруться фактичні prepareViewCfTWS.do?resourceId=... посилання. Картка містить buyer, опис, BVPŽ, дедлайн, дату публікації та явно зазначену EUR-суму. Java date strings EET/EEST і dd/MM/yyyy підтримуються. Для пагінації використовується браузерна сесія та реальні Next/Kitas-контроли, а не вигадані URL.

## Угорщина
Публічна таблиця EKR: notice ID включає /Hxxx, тип оголошення відокремлює присудження від запрошення. Є Chromium-обробка фактичного date-filter, publication sort, Next та Részletek, якщо вони доступні. URL береться з реального href або результату переходу. Модальні деталі без зміни URL ще не розбираються. Якщо список залишився старим, статус stale_source і requested_period_not_reached не дозволяють назвати його актуальним успіхом.

## Естонія
Публічний RHR через Chromium: search-links, реальні #/procurement/ID/... посилання, DOM-картки, вкладка замовника за фактичним href. Немає пошуку випадкових слів у JS і немає вигаданого JSON endpoint. Поточний live DOM ще не підтверджено: при відсутності посилань буде discovery_failed, а не TED fallback чи «успішно, 0».

## Чого RC2 не гарантує
Це native beta, а не сертифікована працездатність усіх чотирьох джерел. 42 тести перевіряють код на синтетичних fixtures, не живі портали. Пагінація, DOM labels та повнота потребують live-підтвердження. Відбір обмежений 3 сторінками й 30 деталями; може не дістатися до релевантних закупівель. Таймаут джерела 180 секунд. Chromium збільшує використання RAM; робота на Render Free без перезапусків не підтверджена.

Після розгортання дивіться /health (2.0.0-RC2, v200-native-rc2) і Status: discovered, details_ok, details_failed, missing_deadline, browser_warning, pagination_unavailable, freshness_lag_days. Немає автоматичного обходу login/CAPTCHA. ADMIN_TOKEN і решта ENV залишаються як у RC1; Chromium встановлюється новим Dockerfile.
